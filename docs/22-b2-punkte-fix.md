## الجزء ١ — نقاط الأقسام

بكل ملف في ١٣ قسم، كل قسم شكله هيك:

```
### Teil: lv1
Format: matching
Titel: Lesen, Teil 1
Gruppe: Lesen
Minuten: 10
Punkte: 1        ← نقاط السؤال الواحد
Maximum: 5       ← مجموع القسم
```

**لازم يتغيّر السطرين `Punkte:` و `Maximum:` سوا.** ولا سطر تاني
بالقسم بينلمس — لا الأسئلة ولا الحلول ولا النصوص.

| القسم | عدد الأسئلة | `Punkte:` من → لَ | `Maximum:` من → لَ |
|---|---|---|---|
| `lv1`  | ٥ | `1`   → **`3`**   | `5`  → **`15`** |
| `lv2`  | ٤ | `2.5` → **`3`**   | `10` → **`12`** |
| `lv3`  | ٤ | `2.5` → **`3`**   | `10` → **`12`** |
| `lv4`  | ٥ | `2`   → **`3`**   | `10` → **`15`** |
| `lvs1` | ٢ | `2.5` → **`3`**   | `5`  → **`6`**  |
| `lvs2` | ١ | `25`  → **`7`**   | `25` → **`7`**  |
| `hv1`  | ٦ | `3` ✅ ما تلمسه | `18` ✅ |
| `hv2`  | ٤ | `3` ✅ ما تلمسه | `12` ✅ |
| `hv3`  | ٤ | `3` ✅ ما تلمسه | `12` ✅ |
| `hv4`  | ٥ | `3` ✅ ما تلمسه | `15` ✅ |
| `hvs`  | ١ | `15`  → **`9`**   | `15` → **`9`**  |
| `sb1`  | ٦ | `2`   → **`0.5`** | `12` → **`3`**  |
| `sb2`  | ٦ | `2`   → **`0.5`** | `12` → **`3`**  |

> **عدد الأسئلة بكل قسم مضبوط ١٠٠٪ زي ما هو — ممنوع تزيد أو تنقص سؤال.**
> الخلل بالنقاط بس.

## الجزء ٢ — نقاط الكتل (Blöcke)

فوق بكل ملف، أسطر ٤ لَ ٣٧، في خمس كتل. هدول الأسطر **مطابقة حرفياً
بالملفات الثمانية**، فبتنبدّل نسخ ولصق.

بدّل سطر `Punkte:` جوّا كل كتلة:

| الكتلة | `Punkte:` من → لَ | الحساب |
|---|---|---|
| `block-lesen`            | `45` → **`54`** | 15+12+12+15 |
| `block-lesen-schreiben`  | `30` → **`13`** | 6+7 |
| `block-hoeren`           | `57` ✅ ما تلمسه | 18+12+12+15 |
| `block-hoeren-schreiben` | `15` → **`9`**  | 9 |
| `block-sb`               | `24` → **`6`**  | 3+3 |

## الجزء ٣ — Aufgabe 58 مفقودة

بالثمانية كلهن الترقيم بيوقف عند **٥٧**. المفروض يكون في:

**`Forumsbeitrag` — السؤال ٥٨ — ١٤ نقطة** (صفحة ٦٥ بالـPDF)

هاد مو تصليح رقم، هاد **محتوى ناقص** — لازم يتجاب نصّ المهمة من
امتحان كل نموذج. الصيغة المطلوبة (نفس شكل `lvs2` الموجود):

```
### Teil: fb
Format: writing
Titel: Schreiben, Forumsbeitrag
Gruppe: Schreiben
Minuten: 35
Punkte: 14
Maximum: 14
Anweisung: <نص التعليمات من الامتحان>
Text:
<نصّ المنشور يلي لازم الطالب يردّ عليه>
Aufgaben:
[58] <صيغة المهمة>
Punkt: <النقطة الأولى المطلوب ذكرها>
Punkt: <النقطة التانية>
Punkt: <النقطة التالتة>
Punkt: <النقطة الرابعة>
```

وبعدها يتزاد `fb` لكتلة، إمّا كتلة جديدة أو لَ`block-sb`:

```
Teile: sb1, sb2, fb
```

مع تعديل `Punkte:` تبع الكتلة (٦ + ١٤ = **٢٠**).

## الجزء ٤ — قرار مفتوح: الـ٢٧ نقطة Grammatik

صفحة ٦٥ بتقول إنّ ٢٧ نقطة من الـ٦٠ تبع Schreiben بتنعطى
«Für Grammatik» — يعني تقييم لغوي عام على كل النصوص المكتوبة، مو
مربوط بمهمة وحدة.

**ما تعملها بلا ما تسأل صاحب المشروع.** إلها تلات حلول، وكل وحدة إلها
أثر على التصحيح الآلي.

## التحقّق بعد التعديل

```bash
node tools/check_content.mjs telc/b2
```

**المطلوب:** ما يطلع ولا سطر فيه `★ نقاط ما بتنطال`، والسطر الأخير
يقول `0 بلوك نقاطه ما بتنطال`.

الفحص **مفعّل وبيوقف البناء** — بالاتجاهين:

- بلوك بيعلن أكتر من يلي قطعه بتعطيه (الطالب ما بيوصل ١٠٠٪)
- بلوك بيعلن أقلّ (الطالب فيه يجيب أعلى من العلامة الكاملة)

في عذر واحد بس: لمّا البلوك مصرّح `Fehlend: n` — هداك نقص مقصود
ومكتوب للطالب بالواجهة، ونماذج B1 الناقصة بتعتمد عليه.

**حدّ معروف:** لو حدا نقّص `Punkte:` تبع قسم وترك `Maximum:` متل ما
هو، المحلّل بيفسّرها «أسئلة ناقصة» وبيمرق. الفحص بيمسك خلل رأس
البلوك، مو كل تناقض جوّا القسم.
