# telc B1 Leseverstehen Teil 3 — Extracted & Enhanced Advertisements

This directory contains all individual advertisements extracted from the 16 official telc B1 exam models plus Modell SONJA3 (204 advertisements total).

Each advertisement has been:
1. **Extracted** individually from its enclosing frame with tight padding.
2. **Enhanced**: Local adaptive 2D background normalization eliminates paper grain, shadows, and scan discoloration, whitening backgrounds to pure `#FFFFFF`.
3. **Text Sharpening**: S-curve contrast enhancement deepens faint ink and makes fine print crisp and legible.
4. **Visual Card Presentation**: Rendered as human-friendly cards (`ad_<letter>_card.png`) with clean rounded frames, bold badge, and German topic titles.
5. **Analyzed**: Mapped to corresponding exam questions (Aufgaben 11–20) from `data/modell-*.json`.
