# telc Deutsch B1 — Mündliche Prüfung (Komplettmodul)

Dieses Modul bietet die vollständige, offizielle und sprachlich lektorierte Vorbereitung für die **mündliche Prüfung telc Deutsch B1 (Sprechen)**. ## 4. Sprachliches Lektorat (Korrekturen der Rohdaten)

Die Ausgangsdateien in `feed pdf/` enthielten handschriftliche Notizen und studentische Transkripte mit zahlreichen orthografischen und grammatikalischen Fehlern. Alle Texte wurden systematisch lektoriert:
- Korrektur von Lautverwechslungen und Tippfehlern (*„Hauze“ ➔ „Hause“*, *„Geburstag“ ➔ „Geburtstag“*, *„Geprächspartner“ ➔ „Gesprächspartner“*, *„Einkäure“ ➔ „Einkäufe“*, *„Betrib“ ➔ „Betrieb“*, *„schencken“ ➔ „schenken“*).
- Berichtigung von Kasus- und Rektionsfehlern (*„Freundin vo Ihnen“ ➔ „Freundin von Ihnen“*, *„an einem Arbeitstags“ ➔ „an einem Arbeitstag“*).
- Anhebung auf idiomatisch einwandfreies, gehobenes B1-Prüfungsdeutsch mit natürlichen Konnektoren (*deshalb, obwohl, trotzdem, einerseits ... andererseits*).
