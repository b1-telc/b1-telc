# telc Training

تطبيق تدريب على امتحانات **telc Deutsch** — مبني ليكون منتج باشتراك:
دخول بكود، محتوى محمي بالسيرفر، لوحة تحكّم، وأكتر من مستوى.
**واجهة التطبيق كلها بالألماني** عشان تكون جوّ الامتحان نفسه.

## شو فيه

- **١٦ نموذج امتحان B1** مقسومين حسب أقسام telc الرسمية، **٩١٢ سؤال**.
- **مؤقّت** بيبلش عند الضغط على «Start» وبيسلّم أوتوماتيكياً لما ينتهي الوقت.
- **تصحيح بالسيرفر**: العلامة والنسبة وجواب كل سؤال مع الحل الصحيح.
- **دخول بكود** بتولّديه من اللوحة: **مستوى واحد** لكل كود، وعدد تفعيلات محدّد
  (افتراضي ٢ = جوال + لابتوب). بلا إيميل ولا كلمة سر.
- **لوحة تحكّم**: المستخدمين، تمديد وتقصير الاشتراكات، الأكواد، المحتوى، سجلّ تدقيق.
- **استيراد**: بتلصقي نص امتحان، بتشوفي معاينة، بتنشري.
- **أكتر من مستوى** (A1، A2، B1…) والاشتراك بيحدّد شو بيفتح.
- **مراجع للقراءة** بتضيفيها من اللوحة والطالب بيقراها أي وقت.

## الحماية — نقطة التصميم المركزية

مفاتيح الحلول **ما بتنزل عالمتصفّح أبداً**. هي بجدول `item_answers` يلي عليه
RLS **بلا ولا سياسة قراءة** — يعني ما في نداء ولا توكن ولا استعلام بيوصله.
التصحيح بينعمل بدالة `submit_attempt()` بالسيرفر، وهي بترجّع الحلول **بعد**
ما تكتب المحاولة. والعميل ما بيقدر يكتب علامته: سياسة الإدخال بتشترط
`points is null`.

مجلد `data/` لسا فيه الـ٨٩٦ حل — **ممنوع ينشر**. صار مجرّد مصدر للمصدّر،
و`tools/build_dist.sh` **بيرفض** يبني إذا وصل للناتج.

## التركيب

**اقرأي [docs/13-setup.md](docs/13-setup.md)** — من مشروع Supabase فاضي لتطبيق شغّال، خطوة خطوة.

باختصار: أنشئي مشروع Supabase ← شغّلي `supabase/migrations/*.sql` بالترتيب ←
حمّلي `supabase/seed/b1.sql` ← ارفعي الصور ← اعملي حساب أدمن ← املأي
`assets/config.js`.

### التشغيل المحلّي
```bash
./run.sh                    # التطبيق على /، اللوحة على /admin/
```

### النشر
```bash
./tools/build_dist.sh       # → dist/ (~200 كيلوبايت)
```

## الاختبارات

```bash
./supabase/tests/run.sh && ./tests/run.sh
```

وبتنشغل أوتوماتيكياً على كل دفع لـGitHub (`.github/workflows/tests.yml`).

**٣٦١ تأكيد** عبر ١١ مشغّل: المخطط والصلاحيات، قفل الحلول، التصحيح، سقف
الأجهزة، إجراءات اللوحة وسجلّ التدقيق، التكرار المتباعد، التعبير الكتابي،
المصدّر، المحلّل، round-trip الصيغة على الـ١٦ امتحان، حقن XSS، والتطبيق واللوحة
والـEdge Function بمتصفّح ومحرّك حقيقيين.

**اقرأي [TESTING.md](TESTING.md)** — فيها كيف تشغّليها، **و١٥ بغ انكشفوا فيها**
(منهن أربعة مالييّن أو موقفين للاستعمال)، وخمس أخطاء بالاختبارات نفسها كانت
بتعطي ثقة كاذبة.

```

assets/app.js           المحرّك: عرض الأسئلة، المؤقّت، النتائج
admin/                  لوحة التحكّم (تطبيق منفصل)
admin/parse.js          محلّل صيغة اللصق + عكسه
supabase/migrations/    مخطط قاعدة البيانات والدوال
supabase/seed/          محتوى B1 كـSQL (مولّد)
supabase/tests/         اختبارات قاعدة البيانات
tests/                  اختبارات المتصفّح والصيغة
tools/export_sql.py     data/*.json → SQL بذر
tools/upload_images.py  رفع الصور لدلو Storage الخاص
tools/build_dist.sh     بناء النشر + حارس تسريب الحلول
data/                   المصدر التاريخي — ما بينشر
Doku/                   الـPDF الأصلي — ما بينشر
```
